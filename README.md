# My Portfolio

This is my personal portfolio website. It shows who I am, my skills and the projects I have built. I made it using HTML, CSS and JavaScript.

Live site: https://YOUR-USERNAME.github.io/portfolio/

## What is in the website

- About me, skills, projects and contact sections
- Dark and light mode
- Works on mobile and desktop
- Click on a project to see its details
- Contact form
- Download my resume

## Tools used

- HTML5
- CSS3
- JavaScript
- GitHub Pages (for hosting)

## How to run it

1. Download or clone this repository.
2. Open the `portfolio` folder.
3. Open `index.html` in your browser.

## How to put it online

1. Create a new repository on GitHub.
2. Push the code to it.
3. Go to Settings, then Pages.
4. Choose the `main` branch and click Save.
5. Wait one or two minutes and open the link.
